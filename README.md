# LAN-Mail
**LAN-Mail** is an educational tool developed for use at the BSC Cyber Quest 2026 summer camp. It requires students to find their own IPv4 address, 
then enter one of their classmates' to send a direct message. Developed using C# and Windows Forms, it does not require any extra installation to work and
can simply be extracted, then run from the ZIP archive. Administrative privileges are required to open sockets and initialize networking functions.
